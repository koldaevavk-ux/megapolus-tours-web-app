## 🚀 Установка и запуск

### Локальная разработка

```bash
# Установка зависимостей
npm install --legacy-peer-deps

# Сборка проекта
npm run build

# Запуск dev-сервера с PM2
pm2 start ecosystem.config.cjs

# Проверка статуса
pm2 list

# Просмотр логов
pm2 logs megapolus-tours-lk --nostream

# Остановка
pm2 delete megapolus-tours-lk
```

### Production деплой на Cloudflare Pages

```bash
# Сборка
npm run build

# Деплой
npm run deploy:prod
```

## 📱 Использование приложения

### Вход в систему

Для демонстрации можно использовать любые данные - аутентификация mock-режиме.

После входа доступны все функции личного кабинета.

### Навигация

- **Главная** - дашборд с обзором
- **Мои туры** - список всех туров
- **Документы** - все документы по турам
- **Сообщения** - чат с менеджером
- **Профиль** - личные данные

### Функции в разработке (Backend интеграция)

⏳ **Требуется интеграция с Битрикс24**:
- Реальная аутентификация через API
- Загрузка данных туров из CRM
- Выгрузка документов из хранилища
- Отправка сообщений менеджеру
- Обработка платежей
- Синхронизация профиля

## 🔧 Готовность к интеграции с Битрикс24

Архитектура приложения подготовлена для подключения backend:

### API endpoints (требуется реализация):

```javascript
// Аутентификация
POST /api/auth/login
POST /api/auth/register
POST /api/auth/reset-password

// Туры
GET /api/tours
GET /api/tours/:id

// Документы
GET /api/documents
GET /api/documents/:id/download

// Сообщения
GET /api/messages
POST /api/messages

// Профиль
GET /api/profile
PUT /api/profile

// Уведомления
GET /api/notifications
PUT /api/notifications/:id/read

// Оплата
POST /api/payments
```

### Структура данных готова под Битрикс24:

Все поля и структуры соответствуют типовым полям сделок и контактов в Битрикс24:
- ID клиента
- Контактные данные
- Данные сделок (туров)
- Документы (файлы из хранилища)
- Коммуникации (активности)
